# 📖 Description du Projet

SmartFood est une plateforme web intelligente qui aide les utilisateurs à cuisiner selon les ingrédients disponibles, réduire le gaspillage alimentaire et améliorer leur alimentation.

Le projet vise à :

- Proposer des recettes adaptées
- Fournir des informations nutritionnelles
- Réduire le gaspillage alimentaire
- Encourager une alimentation saine
- Utiliser l’intelligence artificielle pour suggérer des repas
